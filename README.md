## 📱 About the Project

**ConnectSphere** is a Flutter-based mobile application developed to practice and demonstrate mobile app development using Flutter and Dart.

The project focuses on building a modern user interface, reusable components, organized code, and a user-friendly application experience.

## ✨ Features

- Clean and modern mobile UI
- Responsive screen layouts
- Reusable Flutter widgets
- Organized project structure
- Material Design components
- Android application support

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have installed:

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android emulator or a physical Android device

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/abirprogrammer/Flutter_Batch_02_Assignment.git
```

**2. Navigate to the project directory**

```bash
cd Flutter_Batch_02_Assignment
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Check the Flutter environment**

```bash
flutter doctor
```

**5. Run the application**

```bash
flutter run
```
